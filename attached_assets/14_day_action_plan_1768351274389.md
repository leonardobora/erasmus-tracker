## 🛠️ Tech Setup (Quick Checklist)

**Backend:**
```bash
git clone https://github.com/yourusername/erasmus-tracker.git
cd erasmus-tracker/backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
docker-compose up -d  # Start PostgreSQL
python -m pytest  # Run tests
uvicorn app.main:app --reload  # Start API
```

**Frontend:**
```bash
cd erasmus-tracker/frontend
npm install
npm run dev  # localhost:5173
npm run build  # Production
```

## 💡 Dicas Práticas

### Scraping
- Start com 5-10 programas manualmente pra validar dados
- Usa `time.sleep()` entre requests (ética)
- Cache agressivamente pra não sobrecarregar sites
- Handle exceptions gracefully

### Frontend
- Start com funcionalidade > beleza (deixa TailwindCSS pro final)
- Use React hooks (useState, useEffect)
- Cache API responses em localStorage

### DevOps
- Setup `.env` com variáveis sensíveis
- Use GitHub Secrets pra CI/CD
- Monitore erros com Sentry (free tier)

### Community
- Respond to issues dentro de 24h
- Create good first issues pra novatos contribuirem
- Monthly update posts no blog
